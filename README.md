# APL121 · Бие даалт №1 — Code Quest

Сэдвийн дугаар: №1 — Тэгш, сондгойн өдөр  


## 1. Бодлогын зорилго

Машины дугаарын сүүлийн орон болон тухайн өдрийн гарагийг ашиглан хотын төвөөр зорчих боломжтой эсэхийг тодорхойлно. Мөн гэр бүлийн 3 машины хувьд долоо хоногт хэдэн өдөр зорчиж болохыг тооцоолж, хамгийн олон өдөр явах боломжтой машиныг олно.

## 2. Программын файлууд

- quest.fprg — Flowgorithm программ
- flowchart.png — Блок схем
- pseudocode.md — Псевдокод
- main.c — C хэл дээр бичсэн программ
- tests.md — Программыг шалгах 5 тест

## 3. Программыг ажиллуулах заавар

**C хэл дээр ажиллуулах:**

bash
gcc main.c -o main
./main
```

Windows үйлдлийн систем дээр:
bash
gcc main.c -o main.exe
main.exe
```
Flowgorithm дээр ажиллуулах:

quest.fprg файлыг нээгээд Run товчийг дарна.

## 4. Жишээ үр дүн

Оролт:d = 4, g = 2, гэрийн машинуудын сүүлийн орон 2, 3, 5.

- Өнөөдөр хотын төвөөр явж болно.
- 1-р машин долоо хоногт 3 өдөр явна.
- 2-р машин долоо хоногт 4 өдөр явна.
- 3-р машин долоо хоногт 4 өдөр явна.
- Хамгийн олон өдөр явах машиныг сонгоход 2-р машин шалгарна.

## 5. Программд ашигласан дүрэм

1. Машины дугаарын сүүлийн орон болон гарагийн тэгш, сондгой нь таарч байвал тухайн машин явж болно.
2. Гарагийг 1-ээс 7 хүртэл тооцно. Үүнд 1 нь Даваа, 7 нь Ням гараг байна.
3. Машины дугаарын сүүлийн орон 0-9-ийн хооронд байх бөгөөд 0-ийг тэгш тоонд тооцно.
4. Гэр бүлийн нийт 3 машиныг шалгана.
5. Хамгийн олон өдөр явах машиныг сонгохдоо өдрийн тоо тэнцсэн тохиолдолд эхний машиныг сонгоно.
6. Одоогийн хувилбарт буруу оролтын хүрээг шалгах нөхцөл хараахан нэмээгүй.

## 6. Тестийн үр дүн

Программын ажиллагааг 5 тестээр шалгасан. Үүнд энгийн оролт, тэгш болон сондгой дугаар, хилийн утгууд болон буруу оролтыг шалгах тохиолдлууд багтсан.

Эхний 4 тестэд Flowgorithm болон C хэл дээрх үр дүн ижил гарсан. Харин 5-р тестээр оролтын утгыг шалгах нөхцөл дутуу байгааг илрүүлсэн. Цаашид буруу утга оруулсан үед алдааны мэдээлэл гаргадаг болгох шаардлагатай.

## 7. Дүгнэлт
