# APL121 - C Programming

Энэхүү repository нь APL121 хичээлийн даалгавар болон C хэлний
програмчлалын эхний долоо хоногийн ажлуудыг агуулна.

## Repository-д байгаа зүйлс

- README.md - төслийн тайлбар болон ажиллуулах заавар
- hello.c - "Hello, UFE" хэвлэх C програм

## Хэрхэн ажиллуулах вэ?

C compiler ашиглан hello.c файлыг хөрвүүлнэ:

gcc hello.c -o hello

Дараа нь программыг ажиллуулна:

./hello
